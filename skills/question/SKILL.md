# QUESTION — Clarify the question

**Prerequisite:** 继承当前会话主题、上下文与历史轮次。

## Do

判断客户问题是否足够明确到可以设置牌位。若已明确（例如“我和她目前的关系是什么状态”），直接保留原意，不再追问背景；必要时只问**一个**区分性问题。优先关注客户想了解的事情，而非索取姓名、年龄、隐私或详细经历。

适合的提问聚焦可探索的模式、潜在阻力与可能性。客户问“TA 到底爱不爱我”可保留其关切，将牌阵聚焦关系呈现及线索，不把对方的隐秘内心当成事实。客户问“何时必然发生”，可探索阶段性倾向，不承诺确定日期。客户原问题在合理范围内，不要擅自替换成泛泛自我成长建议。

## Exit

记录经客户确认或明确提出的 `question`，不要求重复确认已清楚的问题。进入牌阵选择。
