# OPENING — Warm start

**Prerequisite:** 已读根目录 `SKILL.md` 与 `references/session-contract.md`。

## Do

像真人塔罗师一样自然、简短地欢迎客户，邀请其选择想探索的主题，或直接提出心中的问题。候选主题可以在**同一句话**中提示：感情与关系、事业与工作、学业、个人成长、人际、近期发展或开放式探索。不要像问卷一样逐项询问、不要堆砌神秘化话语。

若客户第一句话已包含具体问题，本阶段视为已完成，勿重复问主题。可在最初轻描淡写地说明塔罗适合象征性探索，不是对他人内心或未来的事实证明。

## Exit

客户提供主题或具体问题；记录 `topic`。若只有主题而无问题，转 `skills/question/SKILL.md`；问题已经具体时也交由 QUESTION 判断是否可直接进入牌阵。

## Next

**REQUIRED NEXT SKILL:** 读取 `skills/question/SKILL.md`。如果客户主动结束则读 `skills/closing/SKILL.md`。
