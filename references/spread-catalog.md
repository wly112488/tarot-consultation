# Spread Catalog

先根据客户**想弄清什么**确定牌阵。同一个问题可以用不同牌数解读，牌数影响牌位拆分的细致程度，而不改变客户想了解的整体范围。未指定牌数时，通常同时提供 3、5、7 张选项，由客户选择；必须在抽牌前明确各选项的牌位，并在客户选定后固定其牌位顺序与含义。

| 用途 | 牌阵与牌位（严格依次） |
|---|---|
| 单点探索，1 张 | 1. 当前问题的核心提示 |
| 当前局势，3 张 | 1. 现状；2. 主要阻碍；3. 可考虑的行动 |
| 时间发展，3 张 | 1. 过去背景；2. 当前状态；3. 未来可能倾向（不是事实预测） |
| 两个选项，3 张 | 1. A 的可能性及代价；2. B 的可能性及代价；3. 决策时应关注的因素 |
| 感情关系，3 张 | 1. 当前关系与双方互动；2. 主要影响因素（包括对方可能的表现及阻碍）；3. 后续发展倾向 |
| 感情关系，5 张 | 1. 客户在关系中的状态；2. 对方在关系中的*可能呈现*；3. 当前连接；4. 主要阻碍；5. 后续发展倾向 |
| 感情关系，7 张 | 1. 客户在关系中的状态；2. 对方在关系中的可能表现；3. 当前连接；4. 过去及背景影响；5. 主要阻碍与外部因素；6. 可控行动与资源；7. 后续发展倾向 |
| 事业/学业/复杂选择，5 张 | 1. 当前核心局势；2. 支持力量；3. 阻力；4. 可控行动；5. 可能走向 |
| 多因素，7 张 | 1. 核心问题；2. 过去影响；3. 当前内在因素；4. 外部因素；5. 障碍；6. 可控资源；7. 发展倾向 |

感情、事业、学习、人际、自我成长、近期趋势、开放式探索都适用。避免把“对方在关系中的可能呈现”说成对方真实的隐秘心理。客户已有具体牌阵和牌位时，保留并核验牌数及问题适配即可。若客户坚持另订牌位，在抽牌前清晰固定即可。

3、5、7 张均可回应同一关系问题的整体范围，更多牌数用于进一步区分因素，不代表少量牌只能回答部分问题。客户未指定时不因“综合”“一起看”等表述自动选择更多牌；应呈现可选牌数并等待其确认。其他主题也可按相同原则设置不同牌数，但必须使各自牌位适合原问题。
