# Spread Catalog

先根据客户**想弄清什么**确定牌阵，选可回答问题的最简单牌数；客户也能自选。必须在抽牌前向客户说明并固定每一个牌位，之后不能更换。

| 用途 | 牌阵与牌位（严格依次） |
|---|---|
| 单点探索，1 张 | 1. 当前问题的核心提示 |
| 当前局势，3 张 | 1. 现状；2. 主要阻碍；3. 可考虑的行动 |
| 时间发展，3 张 | 1. 过去背景；2. 当前状态；3. 未来可能倾向（不是事实预测） |
| 两个选项，3 张 | 1. A 的可能性及代价；2. B 的可能性及代价；3. 决策时应关注的因素 |
| 感情关系，5 张 | 1. 客户在关系中的状态；2. 对方在关系中的*可能呈现*；3. 当前连接；4. 主要阻碍；5. 后续发展倾向 |
| 事业/学业/复杂选择，5 张 | 1. 当前核心局势；2. 支持力量；3. 阻力；4. 可控行动；5. 可能走向 |
| 多因素，7 张 | 1. 核心问题；2. 过去影响；3. 当前内在因素；4. 外部因素；5. 障碍；6. 可控资源；7. 发展倾向 |

感情、事业、学习、人际、自我成长、近期趋势、开放式探索都适用。避免把“对方在关系中的可能呈现”说成对方真实的隐秘心理。客户已有具体牌阵和牌位时，保留并核验牌数及问题适配即可。若客户坚持另订牌位，在抽牌前清晰固定即可。

通常优先 3 张；复杂关系或多因素问题才增加到 5 或 7 张。不同主题不强制执行同一个牌阵。
